Unity Itch.io

SweepNeko

Project CP213 Mobile Programing

GitHub

This project was developed as part of the CP213 (2nd Year) using Android Studio, Kotlin, and Jetpack Compose. It is an action game for Android where players control a "cat" character by dragging their fingers across the screen, they execute slashing attacks to defeat waves of surrounding enemies. The objective is to survive as long as possible against increasingly difficult waves, utilizing combo mechanics, ultimate abilities, and various power-ups.

BangFire Rising

Project CP112 Object-Oriented Programming

GitHub

This project was developed as part of the CP112 (1st Year) The game was developed using Java, utilizing frames and custom class objects. It is a roguelike game where the player controls "Bangfire," aiming to reach the highest altitude while dodging obstacles and using earned currency to upgrade the firework.
